# Neovim Конфигурация: Полное Руководство и Обзор Функций

Это руководство описывает все функции и возможности вашей модульной конфигурации Neovim, разработанной для TypeScript, React и JavaScript разработки.

## Обзор Конфигурации

Эта конфигурация Neovim предоставляет полнофункциональную среду разработки с поддержкой современных языков программирования и инструментов. Она оптимизирована для работы через SSH и подходит для работы с большими монорепозиториями.

## Основные Функции

### 1. Поддержка TypeScript/React/Javascript

Конфигурация полностью поддерживает разработку на TypeScript, React и JavaScript с использованием Language Server Protocol (LSP).

**Фичи:**
- Автоматическое завершение кода
- Проверка типов
- Навигация по коду
- Поиск определений и ссылок
- Подсветка синтаксиса

### 2. Тема "Bearded Light"

Используется светлая тема с названием "bearded", которая обеспечивает комфортную работу при длительном использовании.

### 3. nvim-tree: Проводник Файлов

Встроенная поддержка проводника файлов для удобного просмотра структуры проекта.

**Команды:**
- `<leader>e` или `:NvimTreeToggle` - открыть/закрыть проводник
- `<leader>f` или `:NvimTreeFindFile` - найти текущий файл

### 4. Telescope: Быстрый Поиск Файлов

Мощный инструмент для быстрого поиска файлов, буферов и других элементов.

**Команды:**
- `<leader>ff` - поиск файлов
- `<leader>fg` - поиск текста во всех файлах
- `<leader>fb` - список открытых буферов
- `<leader>fh` - справочные теги

### 5. Gitsigns: Интеграция с Git

Поддержка Git с отображением изменений в коде.

**Фичи:**
- Отображение добавленных/удаленных строк
- Быстрая навигация по коммитам
- Добавление/отмена изменений

### 5. Работа с Удаленными Репозиториями

Работа с удаленными репозиториями в Neovim с использованием этой конфигурации позволяет эффективно управлять кодом на удаленных серверах.

**Как подключиться к удаленному репозиторию:**
1. Используйте команду `:Git` или `:G` для выполнения Git-команд прямо из Neovim
2. Для клонирования удаленного репозитория используйте `:Git clone <url>`
3. Для работы с ветками используйте `:Git checkout <branch>` и `:Git push`

**Рекомендации по работе с удаленными репозиториями:**
- Используйте `gitsigns` для отслеживания изменений в коде
- Для быстрого поиска файлов в удаленном репозитории используйте `Telescope` (`<leader>ff`)
- Для навигации по файлам используйте `nvim-tree` (`<leader>e`)

### 6. Tree-sitter: Подсветка Синтаксиса

Улучшенная подсветка синтаксиса с использованием Tree-sitter.

**Преимущества:**
- Более точная подсветка
- Поддержка сложных конструкций языков
- Более высокая производительность

### 7. nvim-cmp: Интеллектуальное Дополнение Кода

Расширенное дополнение кода с поддержкой различных источников.

**Фичи:**
- Автоматическое завершение
- Подсказки по типам
- Дополнение из контекста

### 8. null-ls: Форматирование Кода

Интеграция с инструментами форматирования кода.

**Поддерживаемые инструменты:**
- Prettier для JavaScript/TypeScript
- ESLint для проверки кода
- Styling tools

### 9. Оптимизация для SSH/Удаленной Разработки

Конфигурация оптимизирована для работы через SSH соединение.

**Особенности:**
- Эффективное использование ресурсов
- Быстрая загрузка
- Поддержка удаленного редактирования

### 10. Поддержка Монорепозиториев

Оптимизирована для работы с большими монорепозиториями.

**Фичи:**
- Быстрый поиск файлов
- Эффективная навигация
- Удобное управление буферами

### 11. AI Ассистент (Аналог Cline)

Встроенный AI ассистент с поддержкой компании-specific API конфигураций.

**Команды (временно отключен):**
- `<leader>ac` - Открыть интерфейс чата с AI
- `<leader>ai` - Получить предложения по коду
- `<leader>ae` - Объяснить выбранный фрагмент кода
- `<leader>ad` - Сгенерировать документацию
- `<leader>ar` - Рефакторинг кода

**Настройка:**
1. Создайте файл `~/.config/nvim/ai_company_config.lua`
2. Настройте параметры API для вашей компании
3. Или используйте переменные окружения:
   ```bash
   export COMPANY_AI_API_KEY="ваш-ключ"
   export COMPANY_AI_BASE_URL="https://ваш-api-сервис.com/v1"
   ```

**Включение обратно:**
Для повторного включения AI ассистента:
1. Удалите комментарии (`--`) из конфигурации плагина в `lua/config/plugins.lua`
2. Удалите комментарии (`--`) из конфигурации клавиш в `lua/config/keymaps.lua`
3. Перезапустите Neovim

## Установка и Настройка

1. Клонируйте репозиторий
2. Запустите скрипт установки: `./setup.sh`
3. Перезапустите Neovim

## Советы и Трюки

1. Используйте Telescope для быстрого поиска файлов и текста
2. Для работы с Git используйте Gitsigns для отслеживания изменений
3. Используйте AI ассистента для объяснения сложных фрагментов кода
4. Для монорепозиториев используйте `<leader>ff` для быстрого поиска
5. Используйте `<leader>fb` для переключения между буферами

## Решение Проблем

Если возникают проблемы с работой:

1. Проверьте, что все плагины установлены корректно
2. Убедитесь, что LSP сервера запущены
3. Проверьте настройки AI ассистента в `~/.config/nvim/ai_company_config.lua`
4. Перезапустите Neovim после изменений конфигурации
