# Конфигурация Neovim

Это модульная конфигурация Neovim на основе Lua, разработанная для TypeScript, React и JavaScript разработки.

## Особенности

- Полная поддержка TypeScript/React/Javascript с использованием LSP
- Светлая тема "Bearded Light" с улучшенной цветовой дифференциацией
- nvim-tree для функциональности проводника файлов
- Telescope для быстрого поиска файлов
- Gitsigns для интеграции с Git
- Подсветка синтаксиса с помощью Tree-sitter
- Интеллектуальное дополнение кода с помощью nvim-cmp
- Форматирование кода с помощью null-ls
- Оптимизировано для работы через SSH/удаленную разработку
- Совместимо с монорепозиториями и эффективным поиском файлов
- Комплексные сочетания клавиш и документация
- Поддержка вкладок (tabs) для быстрого переключения между файлами
- AI-ассистент с поддержкой компании-specific API конфигураций (аналог Cline)

## Установка

Чтобы установить эту конфигурацию, выполните следующие шаги:

1. Клонируйте этот репозиторий на ваш локальный компьютер
2. Запустите скрипт установки: `./setup.sh`

Скрипт установки выполнит:
- Копирование всех файлов конфигурации в стандартное место хранения конфигураций Neovim (`~/.config/nvim/`)
- Установку необходимых зависимостей (например, lazy.nvim)
- Подготовит всё для использования Neovim

## Использование

После установки перезапустите Neovim для применения конфигурации.

## Хранение в Git

Эта конфигурация предназначена для хранения в Git для удобного контроля версий и совместного использования. Все файлы конфигурации организованы в этом репозитории, чтобы их можно было отслеживать и управлять ими должным образом.

Чтобы использовать эту конфигурацию с Git:
1. Клонируйте этот репозиторий на ваш компьютер
2. Выполните `./setup.sh` для установки конфигурации
3. Зафиксируйте и отправьте свои изменения в репозиторий Git

## Разработка

Эта конфигурация разработана для работы с:
- Neovim через SSH соединение
- Большими монорепозиториями
- TypeScript, React и JavaScript разработкой
